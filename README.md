# EasyClicker

A simple, fast, and lightweight input automation tool for Windows 10 and 11. Built with Python, it allows you to automate clicks and key presses efficiently.

## Features:

* **Autoclicker:** Set custom click intervals in milliseconds with an optional random delay.
* **Hold Mode:** Keep a key or mouse button pressed continuously or use timed intervals.
* **Custom Binds:** Bind any keyboard key, numpad button, or extra mouse buttons.
* **Global Hotkeys:** Use `F6` for the autoclicker and `F7` for the hold mode from anywhere.
* **Auto-Save:** All configurations are automatically saved on exit.

## Getting Started:

1. Go to the [Releases](https://github.com/EasyClicker/EasyClicker/releases) section.
2. Download the latest `Setup.exe` or the Portable `.zip` archive.
3. Launch the application and configure your hotkeys.
